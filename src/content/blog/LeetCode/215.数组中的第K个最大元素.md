## 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

## 示例

### 示例 1

```text
输入：nums = [3, 2, 1, 5, 6, 4], k = 2
输出：5
```

### 示例 2

```text
输入：nums = [3, 2, 3, 1, 2, 4, 5, 5, 6], k = 4
输出：4
```

## 解法一：快速选择

### 解题思路

快速选择类似快速排序的 `partition` 思想，但只继续处理包含目标元素的一侧。利用随机基准值（`pivot`）将数组分为三部分，每次排除不可能包含答案的部分，逐步缩小查找范围。

### 算法步骤

1. **选基准**：随机从数组中选取一个元素作为 `pivot`。
2. **三路分组**：遍历数组，将元素分为三组：
   - `left`：大于 `pivot` 的元素
   - `mid`：等于 `pivot` 的元素
   - `right`：小于 `pivot` 的元素
3. **判断与递归**：根据 `k` 所在的位置决定下一步：
   - 若 `k <= len(left)`，第 `k` 大的元素在 `left` 中，递归查找 `left`。
   - 若 `k <= len(left) + len(mid)`，第 `k` 大的元素就是 `pivot`。
   - 否则，第 `k` 大的元素在 `right` 中，递归查找 `right`，同时将 `k` 减去已经排除的 `left` 和 `mid` 的长度。

### 代码

```python
import random
from typing import List


class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        # 随机选择基准值，降低每次都选到极端值的概率。
        pivot = random.choice(nums)

        # 按照与 pivot 的大小关系，将数组分成三组。
        left = [x for x in nums if x > pivot]
        mid = [x for x in nums if x == pivot]
        right = [x for x in nums if x < pivot]

        # 如果第 k 大元素在左侧，继续在 left 中查找。
        if k <= len(left):
            return self.findKthLargest(left, k)

        # 如果 k 落在 mid 的范围内，pivot 就是第 k 大元素。
        if k <= len(left) + len(mid):
            return pivot

        # 否则在右侧查找，并扣除已经排除的元素数量。
        return self.findKthLargest(
            right,
            k - len(left) - len(mid),
        )
```

### 复杂度分析

- **时间复杂度**：平均 `O(n)`。每次划分后只继续处理包含答案的一侧。
- **空间复杂度**：`O(n)`。列表推导式会创建 `left`、`mid` 和 `right` 三个新数组。

## 解法二：基于堆的算法（最小堆）

### 解题思路

维护一个大小为 `k` 的最小堆。遍历数组时，只保留最大的 `k` 个元素，堆顶的最小值就是全局第 `k` 大的元素。

### Python 中的 `heapq` 模块

Python 没有专门的堆对象，而是通过内置的 `heapq` 模块直接操作普通列表（`list`）。

- **默认特性**：`heapq` 实现的是最小堆，即 `heap[0]` 永远是堆中的最小元素。
- **常用 API**：
  - `heapq.heappush(heap, item)`：将 `item` 加入堆，并自动调整堆结构。
  - `heapq.heapreplace(heap, item)`：弹出堆顶最小值并推入新元素，比先弹出再加入效率更高。
  - `heapq.nlargest(n, iterable)`：直接返回最大的 `n` 个元素，可以用于快速实现，但不适合用来练习堆的操作。

### 算法步骤

1. 初始化空列表 `min_heap`。
2. 遍历数组中的每个元素：
   - 若堆的大小小于 `k`，直接使用 `heappush` 将元素加入堆。
   - 若当前元素大于堆顶 `min_heap[0]`，说明堆顶不可能继续属于最大的 `k` 个元素，使用 `heapreplace` 替换堆顶。
3. 遍历结束后，堆顶 `min_heap[0]` 即为答案。

### 代码

```python
import heapq
from typing import List


class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        min_heap = []

        for num in nums:
            # 先将前 k 个元素加入最小堆。
            if len(min_heap) < k:
                heapq.heappush(min_heap, num)
            # 当前元素更大时，用它替换堆顶的最小值。
            elif num > min_heap[0]:
                heapq.heapreplace(min_heap, num)

        # 堆中保留最大的 k 个元素，堆顶就是其中最小的元素。
        return min_heap[0]
```

### 复杂度分析

- **时间复杂度**：`O(n log k)`。遍历 `n` 个元素，每次堆调整的时间复杂度为 `O(log k)`。
- **空间复杂度**：`O(k)`。最小堆中最多维护 `k` 个元素。
